Lock this device

App lock
Asks for a PIN or passphrase when the app opens. It is a gate on this device, not encryption of the stored data — it stops someone picking up your phone and reading your finances, but it is not protection against a determined attacker with the handset.

Advanced

End-to-end encrypted sync, on your own Supabase project
The default account above syncs to our server as normal data — simple, but we could technically read it if we queried the database directly. This does the opposite: your data is encrypted on this phone before it leaves, using a passphrase only you know. The server stores unreadable ciphertext — without the passphrase nobody, including us, can decrypt it. Slip photos never sync either way.
off
Lose the passphrase and the encrypted copy is unrecoverable. That is the point of it, but write it down somewhere safe.

Your data

🔒 On this device only
• No bank login, ever. At any tier. This app cannot see your accounts and never asks to.
• Nothing is uploaded. Statements are parsed in your phone's memory and the file is discarded the moment it is read. Slip photos are stored in your browser, not on a server.
• No account, no sign-up, no analytics. There is no server to hold your data, which is also why sharing works by sending a file rather than syncing.
• You can take it with you. Export a full backup or a plain CSV at any time.
• The trade-off: because it lives only here, losing this phone loses the data. Back it up.
